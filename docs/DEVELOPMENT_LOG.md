36. Added Prettier (with the Tailwind class sorter) and formatted the codebase; the V0 source was written as single long lines. Rewrote globals.css as design tokens plus Tailwind utilities, replacing ~200 bespoke classes. Kept the V0 palette (graphite, restrained orange). Added Geist Sans/Mono via next/font (self-hosted at build time).
37. Implemented `lib/cube`: a notation parser (outer, wide, slice, rotation moves; amounts; primes; grouping) and a 54-sticker cube engine using 3D sticker rotation so every move type shares one implementation. Verified against reference facelet strings and known group orders (R U = 105, sexy move = 6, T-perm = 2).
38. Implemented `lib/timer/engine.ts`, a pure state machine (idle → ready → running → stopped, with inspection) driven by input timestamps. Elapsed time is always stop − start from performance.now/event.timeStamp; requestAnimationFrame only repaints. WCA inspection: >15 s is +2, >17 s is DNF. The press that stops the timer must be released before new input counts.
39. Implemented `lib/stats`: separated mean, session mean, trimmed average and rolling average; AoN trims ceil(5%) per side (WCA for Ao5, csTimer convention above). Rolling averages use a sorted sliding window and are checked against brute force on 300 values with DNFs. Added median, sample σ, coefficient of variation, PB progression, activity/streak and chart series builders.
40. Storage: added schema v2 (session sortOrder, new timer preferences) with an upgrade function and a test that opens real v1 data. Split repositories into sessions (create, rename, archive, delete with cascade, never delete the last session), solves (add, edit penalty/notes/tags without touching raw time) and settings (defaults merged for old records).
41. Added versioned JSON backup/restore (`lib/export/backup.ts`) with full validation, referential checks, recomputed final times, merge vs replace, and a single transaction. Test forces a failure mid-restore and confirms nothing changed.
42. First scramble provider used cubing.js via a dynamic import. Unit tests passed in Node, but a browser check of the production build showed "Module worker instantiation failed" and a silent fallback to random-move scrambles: webpack copies cubing's worker entry without its dependencies. Resolved by pre-bundling the scrambler with esbuild (the bundler cubing.js supports) into `public/vendor/cubing`, loaded with a native import at runtime and configured to try the esbuild worker strategy first. Added an e2e test asserting random-state scrambles and no failed requests. The random-move fallback remains, clearly labeled in the UI.
43. Built the timer UI: session switcher and manager, scramble panel with 2D cube net, full-viewport focus mode while holding/inspecting/solving, last-solve quick penalties, stats summary, solve history with Ao5/Ao12 per solve, solve details dialog (penalty, notes, tags, delete with undo), touch/pen support, inspection audio cues, and screen-reader announcements.
44. Keyboard guard (`lib/timer/input.ts`): never intercepts inputs, text areas, open dialogs/menus or modifier shortcuts; keyboard-focused buttons keep Space. An e2e run exposed that a nav link left focused after client navigation swallowed Space; links activate with Enter, so they were removed from the guarded controls and a unit test was added.

## UI overhaul (2026-09-13, branch `ui-overhaul`, not pushed)

The owner found the V1 interface bland and asked for a drastically more polished, interactive UI using 21st.dev resources, inspired by TAGDA Timer and csTimer.

49. Studied both references in the browser. TAGDA Timer: animated aurora shader, draggable glass panels, 3D cube preview, theme presets, shortcuts for everything. csTimer: dense and keyboard-first, live averages under the digits, LCD digits, sortable session table.
50. 21st.dev shows component code only to signed-in users; the owner signed in themselves in the preview browser. The registry then returned code, but free accounts are limited to two component downloads per day and the discovery requests used both. Components were therefore chosen on 21st.dev and taken from their authors' public registries (Aceternity Glowing Effect, Magic UI Border Beam/Magic Card/Confetti) or packages (NumberFlow, paper-design shaders). Motion-primitives' registry rate-limited requests, so its components were not used.
51. Replaced next-themes with a theme engine: six presets with CSS tokens, "Match system", a localStorage-backed external store read with useSyncExternalStore, and a boot script that applies the theme before first paint.
52. Added an animated WebGL mesh-gradient background that pauses during solves and for reduced motion.
53. Rebuilt the shell: floating pill navigation with a sliding indicator, mobile tab bar, command palette (⌘K) fed by a command registry, shortcuts help (?), and an Appearance sheet (T).
54. Rebuilt the timer page as a full-bleed canvas: scramble bar with history and custom scrambles, digit styles (Clean, LCD with ghost segments, Dot) and size, hold and inspection meters, live Ao5/Ao12, draggable glass panels for times (sortable, clear with undo), stats (NumberFlow, sparkline) and an interactive 3D cube, a PB border beam, toast and confetti, plus single-key shortcuts that never fire while typing or solving.
55. Moved the 3D cube's idle spin into motion values after noticing it re-rendered React every frame. NumberFlow renders in a shadow root and leaks a style tag into textContent, so plain-text copies now carry the values and test ids.
56. Owner request: mouse clicks must never control the timer. Pointer handling now ignores `pointerType === "mouse"` for both starting and stopping; touch and pen still work. Added an e2e test that holds and clicks the mouse on the timer.
57. The production build failed: the now-client `FeatureCard` received icon components from server pages. Made it a server component again, with only the glow effect as a client component.
58. The first e2e run had 15 failures and took 6.7 minutes. Headless Chromium renders WebGL on the CPU (SwiftShader), so the shader starved the main thread, and machines without GPU acceleration would see the same. The background now detects software renderers and shows one still frame, and renders at capped resolution. The last-solve bar's exit animation briefly rendered two copies of its controls, so it was removed.
59. A second run still had 12 failures after 8 minutes. System load averaged ~60: the checkout sits in iCloud-synced `~/Documents`, so builds, test artifacts and the dev server's file watching kept fseventsd, fileproviderd and cloudd busy. With the dev server stopped and Playwright on one worker with artifacts outside iCloud, 32/33 passed in 1.4 minutes. Recommendation: move the repository out of `~/Documents`.
60. The remaining failure was real: a panel dragged and then reloaded immediately lost its position, because motion fires `onDragEnd` on the next frame. Positions now also save on `pagehide` and on reset. The cube's idle spin repaints a blurred panel every frame, so it now runs only when a hardware GPU is present.
61. Screenshot review found the LCD ghost segments misaligned (different letter-spacing), Doto's decimal point drawn as a "+" (easy to confuse with a +2 penalty), and content showing through the phone tab bar. The ghost now shares the digits' metrics, the Dot style draws a square pixel for the decimal point, and the tab bar has a solid surface.
62. Final validation: typecheck, ESLint and Prettier clean; 66 unit tests pass (9 files); production build passes; 33 Playwright tests pass in 1.1 minutes (one worker).
