# SolveLab overview

## Shipped

**3.0 — Diagnostic coach.** Set a goal pace, then time Cross, Cross + first pair, F2L, OLL, and PLL. Slow / average / fast tags against that goal. Bluetooth timer path from 2.2 and the daily timer stay. Train and Learn are off until later.

**2.2 — Hardware timer and first coach.** Bluetooth timer mode (Web Bluetooth when available + Stackmat simulator), on-device rule-based coach with training plans, Train exercise arming, and Learn lesson plans with local progress.

**2.1 — Interface.** Screen-fitting timer layout with even panel spacing, optional 3 decimal places, panel positions synced to the Google account, and a slightly wider scramble bar.

**2.0 — Accounts and cloud times**

- Daily timer with WCA inspection, sessions, penalties, stats, and JSON backup
- Themes, command palette, and keyboard-first timer
- Google sign-in; times sync to Cloud Firestore
- Privacy and Terms pages

## Planned

**3.1 — Training.** Practice each CFOP stage after the diagnostic, with tags that update as you train. Algorithm drills start.

**3.2 — Learn and algorithms.** Lesson plans, plus algorithm variants, diagrams, and mastery tracking.
