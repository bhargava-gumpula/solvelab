# SolveLab v3 — STUDIO

A premium editorial bento. Light-first (Linen), ink-on-paper typography, one electric studio-blue accent, and motion that feels machined rather than decorative.

## 1. Concept

**"A beautifully typeset instrument."** Studio treats a speed timer the way Apple treats a product page or Linear treats an issue tracker: calm paper, big confident type, and every number set like a magazine headline. The page is a **bento dashboard** of tiles, each tile answering one question (What do I solve? How fast am I? Am I improving? What do I learn next?). When you put your hands on the cube and hold space, the timer tile **morphs to full screen**, everything else dissolves, and the digits "inhale" (variable-font weight and width rise with the hold) before snapping to bold when you stop.

### Why it beats TAGDA

| TAGDA                                                       | Studio                                                                                                                                                                                                                                 |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dark glass over one purple/teal blob; generic "gamer" look  | Light-first paper with ink type and a single accent; a look nobody in cubing owns. Matching after-dark "Ink" themes                                                                                                                    |
| csTimer layout: three floating glass panels around a number | A bento grid where every tile is an insight; the timer tile is the hero and morphs to full screen when timing                                                                                                                          |
| ~20 toolbar icons with one-letter hotkeys                   | Two-level editorial navigation (tab capsule + section index), one utility capsule, ⌘K for everything                                                                                                                                   |
| Monospace pastel `0.00`                                     | One calm numeral: the interface grotesk at one weight with tabular figures in every state (council fixes), hundredths at three quarters of the seconds, state shown by colour, meter and a green ready field; rolling NumberFlow stats |
| Charts behind "Open the full charts"                        | Insights on the timer page itself: trend, consistency heatmap, milestone distance, session goal ring                                                                                                                                   |
| No reward loop, no teaching                                 | Milestone distance ("Sub 15: 0.84 s to go"), PB ceremonies (gold beam, delta chips), and a magazine-style Learning Hub with course covers and a next-lesson story                                                                      |
| Static background                                           | Living studio light: soft skylight rays that lean towards the cursor, a dot grid that lights under the pointer, paper grain. All of it freezes and dims when you start timing                                                          |

### Typography (all self-hosted with `next/font`)

| Role                                      | Font                                                                      | Why                                                                                                                           |
| ----------------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Interface, figures, scramble and the time | **Instrument Sans** (variable wght 400–700, wdth 75–100, tabular figures) | Crisp grotesk with character; the time is 500 weight with `tnum` in every state, figures and the scramble 400 (council fixes) |
| Editorial display                         | **Instrument Serif** (regular + italic)                                   | Magazine headlines and italic accents ("Solve*Lab*", course titles, big insight numbers)                                      |
| LCD / Dot digit options                   | DSEG7 / Doto                                                              | Kept for the Appearance sheet; downloaded only when chosen, not part of the two-family default                                |

Type scale: display 72–120 px serif (tight -0.02 em), H1 40–56 px serif, H2 24 px sans 600, body 15 px, eyebrow 11 px sans 600 +0.16 em uppercase.

### Surfaces and icons

- Tiles: 1.6 rem radius (`corner-shape: squircle` where supported), warm white at 84 %, 1 px hairline, a two-layer soft shadow and an inset top highlight. Cursor spotlight on hover (pointer: fine only).
- Liquid glass for floating chrome (nav capsule, dock): blur 16 px + saturate 180 %, specular rim (inset highlight + hairline), and in Chromium an SVG displacement lens (`#studio-lens`).
- Icons: lucide at 1.6 stroke, 16/18 px, always paired with a label on first level navigation.
